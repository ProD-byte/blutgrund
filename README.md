# Blutgrund

Ein düsteres Action-Rollenspiel – allein, zu zweit am geteilten Bildschirm oder im WLAN.

## Installieren
1. Unter **[Releases](https://github.com/ProD-byte/blutgrund/releases/latest)** die Datei **BlutgrundSetup.exe** herunterladen.
2. Starten – Blutgrund wird für deinen Windows-Benutzer installiert (ohne Administratorrechte).
3. Fragt Windows beim ersten Start nach der Firewall: Zugriff im **privaten Netzwerk** erlauben (nötig fürs Spielen im WLAN).

## Updates
Blutgrund sucht beim Start selbst nach neuen Versionen und lädt sie automatisch.

## Im WLAN zusammen spielen
Beide starten Blutgrund im selben WLAN. Einer wählt im Pausemenü **👥 Mehrspieler → Spiel im WLAN eröffnen**,
der andere findet das Spiel unter **👥 Mehrspieler** (oder auf dem Titelbildschirm **Im WLAN mitspielen**) und tritt bei.
